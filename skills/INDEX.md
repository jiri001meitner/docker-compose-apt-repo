# Skilly

Závazné postupy pro opakované úkoly, jeden úkol = `skills/<nazev>/SKILL.md`.
Odpovídá-li zadání řádku, načti `SKILL.md` dřív, než začneš měnit soubory.
Fakta patří do `knowledge/`.

| Skill | Kdy |
|---|---|
| [pridani-zrcadla/](pridani-zrcadla/SKILL.md) | Přidáváš, měníš nebo odebíráš zrcadlo v `config/mirrors.json`; report hlásí „never synced“ nebo „No public key“. |
| [novy-zakaznik/](novy-zakaznik/SKILL.md) | Zakládáš účet nebo token, prodlužuješ, blokuješ, rotuješ; automatizace `account ensure` / `token sync`. |
